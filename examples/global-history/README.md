# 《全球通史》的开篇是怎样写出来的
读者想弄懂不同地区的历史怎样发生联系。我们选了家常的一口辣椒，让第一段就有一件可追问的事。

![公众号封面“一口辣椒里的世界史”](cover.jpg)
## 成稿片段
> 吃火锅的时候，谁会特意想一想辣椒的来历？

稿件接着写川菜、湘菜和桌上的辣椒油，再告诉读者辣椒原产美洲。随后追问它怎么来到中国，为什么有人愿意种、愿意吃。航线、买卖和各地的生活由此进入正文。
## 三个可以复用的编辑动作

1. **选择读者碰得到的东西。** 辣椒能让读者先想到一顿饭，接下来才有理由追问这顿饭和别处的历史怎么连上。
2. **拆开需要核实的事实。** 原产地、何时传到中国、何时在某个地方普及，是三个问题。示范引用支持原产地和跨洋传播，具体年代和地方普及另需相应资料。[牛津大学植物标本馆｜辣椒属](https://herbaria.plants.ox.ac.uk/bol/plants400/Profiles/cd/Capsicum)
3. **用封面提示同一个问题。** 「一口辣椒里的世界史」配一碗辣椒、一艘船和地图，把正文的起点和空间变化放到同一张图上。

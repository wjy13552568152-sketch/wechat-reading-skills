# 公众号文章排版
1. 接收定稿与可用素材。输入是 Markdown 时，顺着现有小标题和段落整理为[排版清单](references/article-manifest.md)。保留原句、署名、引语及正文顺序。图像保留用途、图注和替代文字。
2. 首屏按作品需要放剧透提示和全书图，开篇紧随其后。正文每张图解决对应段落的理解难点。文末有原书资料时采用居中书封卡。资料来源用短名称。
3. 用本技能附带的 `scripts/render.py` 生成公众号 HTML 片段与本地预览。默认取清单目录内的本地素材，把图片拷到输出目录。指定主题时只填写文档支持的颜色字段。
4. 打开 `preview.html`，检查标题、首屏、段距、图注和书封卡。版面改动核对正文和图片顺序。实际粘贴至公众号时按编辑器要求重新上传本地图片，并在手机端预览。
交付 `article.html`、`preview.html` 和同目录的 `assets/`。这套本地工具使用离线输入输出。

# 公众号读书文章写作
1. 确认读者、任务与材料范围。用户要先看方案时，交付角度、主线、要核对的事实和一种合适的开场。用户要求成稿时，按可核对的材料直接开写。由目录或节选推出的内容写明范围。
2. 找到一个读者已经在意、且正文能够回答的问题。选一个具体场景、人物动作或生活物件开篇；故事需要有可核对的处境、动作和变化。标题、封面短文案、摘要与开篇兑现同一件事。好奇可以来自熟悉经验遇到意外，不靠编剧情、虚假的现场感或夸大结论。
3. 用少量章节推进一条主线。文学把人物的关系、选择和转折一起写；方法类讲清问题、机制、条件和可尝试的动作；历史说明时间、地域、联系与史料口径。反复讲同一件事的段落可合并。
4. 让来源跟着主张走。重要事实、数字、引语和案例分别记录原书章节或外部来源；把作者观点、第三方材料和编辑解读写清楚。缺出处的说法删掉、收窄或标为待核。合成情境清楚标示。
5. 结尾回应开篇。方法类可给一个带条件的做法，故事类可落在人物的新认识、具体动作或尚未解决的问题。
6. 给每张图写清“读者从图里看懂什么”。故事首图把人物的行动接到关键事件，方法首图画机制和条件。总图和局部图分工。首屏剧透提示的范围随作品决定。
交付正文 Markdown。另给精简的来源和配图简报。只交方案时使用[提纲模板](references/brief.md)。需要审稿或排版时，可与本套件的 `wechat-reading-review`、`wechat-reading-layout` 配合。
